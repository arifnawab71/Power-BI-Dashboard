# Power-BI-Dashboard
This dashboard entails the Pulmonic Studies data from visit compliance, adverse events, enrollment, protocol deviations, safety observations, and core labs domains.

Executive Summary

The Pulmonic Franchise Dashboard Project Requirements v1 defines a Power BI reporting solution designed to provide centralized oversight of clinical study operations across the Pulmonic Franchise. The initiative consists of three key workstreams: Data Lake integration, Power BI dashboard development, and Heartbeat Email automation. The proposed framework is intended to be scalable and reusable across multiple Pulmonic studies.

The dashboard will provide comprehensive visibility into critical clinical and operational performance indicators through eight integrated modules:

Visit Compliance: Monitor expected versus completed visits, missed visits, out-of-window visits, and overall compliance rates.
Enrollment: Track screening, enrollment, treatment milestones, and subject status progression.
Protocol Deviations: Analyze deviation trends by severity, category, and study impact.
Queries: Measure query volume, resolution status, and aging to support data quality oversight.
ISF Reconciliation: Monitor investigator site file completeness and document reconciliation status.
CTMS Action Items: Track operational follow-up activities, ownership, priorities, and overdue items.
Safety Observations: Provide visibility into open observations, pending actions, and resolution performance.
Core Labs: Monitor imaging workflows and core lab processing metrics, including performed, pending, sent, removed, and read studies.

By consolidating these metrics into a single reporting platform, the dashboard will enable study teams to proactively identify risks, improve compliance, enhance operational efficiency, accelerate issue resolution, and support data-driven decision-making across clinical trial execution.
